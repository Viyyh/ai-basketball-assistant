# 本次素材的个性化设置

个人复盘页面新增选填配置，使用现有账号与版本锁、审核历史保护。球员姓名留空使用原衣色/队伍＋号码；提供姓名则显示“姓名 · 号码标签”，不使用姓名作为稳定身份ID。名字保存在本地会话数据库，不写入源码。

可填写场地名、室内外、画面覆盖范围、场地长宽、篮筐高度、三分弧半径、赛制、内外线/罚球分值、每节时长、节数、目标得分、进攻时限、其他约定及分析目标。未知尺寸与计分规则保持null，不自动套用NBA/FIBA数值。参数有基础范围和分值矛盾校验，但没有声称完成现场几何验证。

配置保存为会话版本快照；个人报告与JSON导出包含同一配置。旧版本保存在history，旧页面提交返回409。远程网关对settings写入使用同样的账号权限、同源和强制署名检查；只读账号不能保存。

当前入口为本地/远程个人复盘页面的“本次素材与分析设置”。视频上传、小程序表单、旧业务API参数层之间尚未统一；这些配置目前不会改变模型推理、既有场地参数或自动计算得分。尺寸不能代替图像标定，分析目标不意味着对应识别功能已经实现。下一阶段才进行统一映射与报告计分规则接入。
