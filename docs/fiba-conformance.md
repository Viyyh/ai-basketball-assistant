# FIBA 规则符合性对照

本文件回答一个问题：**报告里的每一个数字，是按谁家的规则算出来的。**

依据是 FIBA《篮球规则》（中文版）第 2 章「比赛场地和器材」——由产品负责人提供的规则书照片（pp. 7–11），加上 FIBA 官方对 3x3 场地尺寸的说明。原文页码随行标出，便于回查。

## 2. 本轮修正（2026-10-21）

**3x3 场地长短边写反了。** 原实现是 `length=15 / width=11`，正确应为 `length=11 / width=15`。

后果不是"图看着不对"这么轻：`y_half` 会变成 5.5 m，而底角直线段要求半宽 > 6.60 m，于是 3x3 被判定成「纯弧线」几何——**底角两分会被算成一分**，且不报错。修正后半宽 7.5 m，3x3 与 5v5 一样是「弧线 + 底角」，符合规则书 2.5.4 对三分线的定义。

决策记录见 `docs/decisions.md` 的 ADR-014。

## 4. 已知局限（会体现在报告可信度上）

1. **判定位置 vs 实际规则**：FIBA 按"球员最后接触地面的点"判断二分/三分，我们用的是检测到的**出手点坐标**。出手点与落脚点通常相差 0.2–0.5 m，正好贴近三分线的出手存在天然争议。报告因此在三分线附近不做「压线」判定，只输出 `distance_m` 供教练自己看。
2. **线宽被折叠成一个阈值**：5 cm 线宽在数学上是 `[6.70, 6.75]` 的一个带，实现上用 `> 6.75` 近似，误差 2.5 cm，远小于坐标标定误差，可接受。
3. **只覆盖半场进攻方向**：坐标系以"本节我方进攻的篮筐"为原点，`periods[].attacking_basket` 记录每节方向。全场两框的镜像翻转在展示层做，不在判定层做。
4. **3x3 的 2 分线**：严格沿用 2.5.4 的同一套三分线定义（弧 + 底角），只是分值换成 1/2 分。若某地 3x3 场地不画底角直线段，需在新建活动时覆盖几何参数——目前接口只开放了半径覆盖，尚未开放几何覆盖。

## 5. 关于速记里的两处笔误

产品负责人的速记里有两处与规则书原文不符，记录在此避免扩散到实现：

- **「限制区……宽 3.6 米」** → 3.60 m 是**罚球线的长度**（2.5.3 第一段）；限制区宽是 **4.90 m**，由端线中点两侧各 2.45 m 定出（2.5.3，图 3 明确标注「4.9 米」）。
- **「弧顶到边线内沿 0.9 米」** → 0.90 m 是那两条**平行于端线的直线**到边线内沿的距离（2.5.4 第一条），也就是底角三分线的位置；弧顶在球场中轴上，与边线无关。

附带一条：NBA 三分线是 **7.24 m**（弧顶），不是 7.25 m。与 FIBA 的差别来自 NBA 的弧线与底角线是两套半径。
