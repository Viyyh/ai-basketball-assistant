# 受保护的远程复盘与人工核查

2026-11-02。统一入口提供临时HTTPS网址，用户名/密码白名单限制访问；本机后端和SQLite不直接暴露到网络。不是公开匿名的数据集或视频网站。

## 默认账号权限

| 角色 | 个人复盘 | 独立二审库 | 外部标签核查 | 主素材库 | JSON导出/账号管理 |
|---|---|---|---|---|---|
| owner 管理员 | 可纠错 | 可审核 | 可审核 | 可审核 | 可导出；账号仅本机命令管理 |
| reviewer 审核者 | 可纠错 | 可审核 | 只读 | 不开放 | 禁止导出 |
| viewer 查看者（可另建） | 只读 | 只读 | 只读 | 不开放 | 禁止导出 |

远程个人复盘修改的是本机个人复盘库。对外素材二审写入独立的 `external-review.db`，不自动覆盖主库；管理员可在主库页审核。外部标签核查的默认审核账号只有查看权限。每次写入由网关强制用登录账号署名，不接受前端伪造审核者。

查看视频的授权用户仍可通过浏览器保存内容；只读是禁止修改，不是防截图或防下载DRM。请只给适合查看该素材的审核者账号。原始SQLite文件不通过任何网关路径提供，即便管理员也没有通用文件下载或SQL执行页面。

## 本机位置

- 当前网址：`data/access/public-address.local.json`。隧道重启会变化，旧网址不能保证继续可用。
- 白名单及加盐PBKDF2-SHA256密码哈希：`data/access/gateway.local.json`。
- 供所有者查看的初始/重置密码：`data/access/credentials.local.json`，权限0600，**只分享对应审核账号，不分享整个文件或owner**。
- 访问日志：`data/access/access.jsonl`，最多当前约10MB与上一份滚动日志。记录账号、来源IP、方法、路径、响应状态，不记录密码、请求正文或完整查询参数。
- 隧道和各服务日志：同一access目录。全部位于Git忽略的data目录，不提交GitHub。

使用浏览器HTTP Basic登录框输入账号密码。公网只接受HTTPS；账号退出/切换建议使用独立隐私窗口并关闭该窗口。此实现不提供自定义会话注销按钮。账号停用和密码重置在下一次请求生效，已经开始的授权视频传输可能继续完成。

## 增加、停用或重置账号

```sh
# 每位审核者建议用独立昵称账号；密码自动生成，写入本机凭据文件。
python3 scripts/review_gateway.py --user alice --role reviewer
python3 scripts/review_gateway.py --user bob --role viewer
python3 scripts/review_gateway.py --user alice --disable
# 对同一账号再运行--user会重置密码；不要误用在仍需保留旧密码的账号。
```

这些命令不要求重启服务。账号配置读写使用锁和原子替换，避免隧道网址更新覆盖刚修改的白名单。只向管理员提供本机账号管理，不向远程用户暴露管理接口。

## 启动、守护与关闭

```sh
# 首次生成本地账号配置（已存在则不覆盖）
python3 scripts/review_gateway.py --setup
# 安装当前用户的登录启动项，保持服务异常后自动重启
python3 scripts/install_remote_review_agent.py
# 移除自动启动并关闭这组远程服务，保留所有数据库和账号文件
python3 scripts/install_remote_review_agent.py --remove
```

LaunchAgent为 `com.victor.basketball-review`，当前用户登录后运行；supervisor管理网关8014、四个专用后端18010/18011/18012/18013和cloudflared。均仅绑定127.0.0.1。不会把电脑其他服务、磁盘目录或SQLite端口发布出去，也不改变原有8010/8012/8013本机入口。

必须电脑开机、联网并处于可运行状态。关机、断网、休眠或部分合盖情形会中断访问；自动启动不等于24小时云服务器。没有为了本功能关闭系统休眠或启用远程唤醒。

Cloudflare Quick Tunnel只提供临时随机网址，适用于当前测试分享；不保证生产可用性。官方说明：[Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。后续取得域名和Cloudflare账号后，可换命名隧道及固定域名，保留同一权限入口。

旧的直连二审公网隧道已停止，现用此统一入口。旧本机二审服务仍可保留，但没有继续通过旧隧道对外发布。

## 已实现的边界

- 所有入口、API、媒体和Range请求先鉴权；普通账号不能进入主库、导出审核JSON或读取任意文件。
- 密码每账号独立盐、600000轮PBKDF2；短时校验缓存不绕过实时enabled/权限/新密码哈希检查。错密码同IP达到8次后限制10分钟。
- 写入要求同源Origin，仍保留子系统审核令牌/版本校验；写入账号由网关覆盖。修改次数和记录仍在各业务库保留。
- 转发只允许预定义应用、路径和方法，不提供任意URL代理；客户端登录Authorization不会转发给普通后端。二审的旧内部Basic凭据只用于本机专用后端。
- 标记no-store、noindex和防嵌入/内容安全策略。未知Host拒绝；HTTP公网请求不弹出密码挑战，要求HTTPS。
- 本地密码文件、日志和启动项权限0600。15项合成账号/后端测试覆盖匿名阻断、白名单、撤销、密码轮换、角色、同源与署名、媒体Range和文件权限等。

没有声称经过独立安全审计或部署了双因素认证。身份权限变更、对外网址和启动状态应由所有者按实际分享需要管理。
