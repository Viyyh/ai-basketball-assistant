# 拍摄指南（统一入口）

2026-11-01：当前统一要求为 [篮球实拍素材任务书 v2.0](video-delivery-spec.md)，可直接转发 [8页可打印PDF](shooting-task-v2.pdf)。

先交30–60秒原始试拍和设备/场景说明；确认后再安排正式连续拍摄。按个人训练、半场比赛、进阶空间分析分别检查覆盖范围。1080p可试拍，半场远景优先4K；固定机位优先，标定和背号按目标任务选配。

旧版从单个视频推导的像素/机位距离表不能作为大众场景的成功保证，已移除。旧PDF的具体问题与修订原因见 [审阅说明](shooting-guide-review.md)。
