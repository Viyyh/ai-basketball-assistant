# 比赛日清单

当前完整要求和可打印检查表见 [任务书第08节](video-delivery-spec.md#08现场核对与异常处理可单独打印) 与 [PDF第8页](shooting-task-v2.pdf)。

1. 拍摄目标及允许用途明确，机位安全、稳定，存储/电量充足。
2. 试拍30–60秒，回放确认目标入画、球和篮筐清楚、快速运动无严重拖影或频闪。
3. 录制连续原片；记录机位变化、中断、遮挡。手机过热先安全停机降温。
4. 记录session_id、设备、场地匿名ID、拍摄目标及实际设置；空间任务另拍参考并记录实测点位。
5. 检查原片可播放且时长完整，原文件传输并备份；标签可由项目方后续审核，不猜未知事件。

不再统一要求4K、40GB、背号可读、真实姓名或米制标定；按实际任务和试拍结果确定。素材进入待审核库不等于获准训练或已完成准确率验收。
