# 原拍摄任务书审阅与修订说明

2026-11-01。审阅用户提供的14页v1.0《篮球比赛视频拍摄任务书》，保留原文件，不将原附件公开提交。修订稿见 [完整要求](video-delivery-spec.md) 与 [可打印PDF](shooting-task-v2.pdf)。

结论：原版适合作为固定半场采集流程的草稿，不能直接作为大众训练产品的统一验收规范。

| 原版位置 | 问题 | v2处理 |
|---|---|---|
| 1–4、11–13页 | 把4K、球25像素、背号可读当统一硬门槛，固定距离/焦段保证“完整报告”；项目无对应泛化证据 | 按任务分级，1080p可试拍，4K为半场推荐，实测原片及推理后的细节 |
| 2页 | 3x3说明出现“10个人全在画面里” | 改为3v3通常6人，不限制只有3x3 |
| 4–6页 | 强制6–10米高机位、色温、快门和全部防抖关闭；以画面变窄判断光学变焦不可靠 | 安全位置优先，按设备与光照实测，记录实际设置 |
| 7页 | 建议忽略手机发热提示 | 改为停机安全降温 |
| 5、7、11页 | 机位一动整段作废、无标定/名单就只能演示 | 切段并限定任务用途；真实姓名非必需，米制任务才需要标定 |
| 8页 | x=0为底线，却给底线端点(0,0)、(11,0)，中线又混用15米；坐标表不自洽 | 移除坐标表，要求现场实测、统一坐标及独立检查点 |
| 8、14页 | 标定用途缺少平面适用范围说明，统一5像素误差门槛 | 说明平面适用范围，禁止未验证的三维与通用阈值承诺 |
| 9页 | shot_type混用动作和分值，时间只精确到秒且抽查容差2秒 | 分开动作/分值/结果，原片秒数与逐帧核验，按任务预设容差 |
| 9–11页 | 没有标准答案就判废，50次出手被当统一充分条件 | 原片可待审核收录，标签由项目方协助；数量只是首轮建议 |
| 整体 | 缺少个人动作、负样本、遮挡unknown、版本溯源及跨会话隔离 | 补充任务覆盖、困难案例、复核、分组与盲测规则 |

v2保留原版有效实践：固定机位首轮采集、先试拍、原片交付、连续片段、场景参考、人工记录与校验。不保留未经验证的像素成功率表与设备距离保证。

PDF由 `scripts/build_shooting_guide.py` 从同一Markdown生成，避免网页要求与拍摄任务书各说一套。模板可用于采集计划，不替代实际逐片质量审核。
