# 篮球实拍素材任务书 v2.0

2026-11-01｜适用于个人训练、半场实战和后续多场地评测

## 01｜先交试拍，再安排正式采集

目标：获取可核验、可复用的真实篮球素材。拍摄合格不等于模型必然分析准确；目前项目仍处于本地检测、审核和评测阶段，尚未实现可靠的全自动比赛分析。

第一次只需提供：30–60秒原始试拍、设备与拍摄目标、同机位场景照片。确认画质和覆盖范围后，再拍1–3分钟连续训练；半场实战可录10–15分钟，时间充裕再增加会话。以上是首轮采集建议，不是训练充分性的保证。

个人训练优先：投篮、上篮、运球或脚步选一个目标。半场实战可选1v1、2v2、3v3；不要求固定球队、标准球场或专业球衣。3v3通常场上6人。

先说明想验证什么：出手与结果、动作姿态、球员跟踪、战术配合、还是空间位置。不同任务所需画面不同，不必一次满足全部高级要求。

拍摄者只负责录好原片和记录客观信息。人工标签可以由项目方后续完成；没有标签的原片先进入待审核库，不能直接用于准确率验收。

## 02｜画面与设备：按任务分级

基础推荐：原始1080p、30fps及以上可进入试拍；条件允许优先60fps。半场广角远景优先尝试4K，但4K不是统一准入门槛，1080p也不自动判废。分辨率和帧率都不能替代清晰度检查。

投篮/上篮：出手者、球的飞行范围、篮筐和篮板尽量同时可见；篮筐上下及两侧留余量。不要让球在最高点出画，也不要只拍到球入网而没有出手过程。

姿态/脚步：身体从头到脚完整可见，手腕、膝踝尽量清楚，避免贴边截肢。单侧机位看不到的关节可标记未知；不能据单一视角承诺准确三维动作或伤病判断。

半场战术/跟踪：尽量完整覆盖目标半场、篮筐、主要边线和所有参与者。拍不全时明确可见区域；区域外事件不计为漏检。全场5v5、跟拍和移动机位作为后续难例单独采集。

身份识别是选项：两队衣色有区分更好；如需按人统计，可用匿名球员ID和可见号码，不要求真实姓名或统一背号尺寸。背号不可读不影响素材用于球/筐或部分动作任务。

试拍回放原片：检查近端和远端快速运动、球、筐和遮挡。不要仅凭“25像素球/30像素背号”验收；本项目未验证通用像素阈值。模型缩放后的可见性也须实测。

## 03｜机位、设置与安全

首轮优先稳定三脚架或牢固支撑，横屏固定拍摄；个人近景竖屏可单独试拍，保留原方向。移动/手持素材保留为困难场景，不与固定机位结果混报。

机位选安全的场外位置或现有看台，略俯视以减少遮挡。先保证目标可见，再调整距离与焦段；不规定21–25米距离或6–10米高度。不要攀爬架高设备，不占用跑动区、底线落地区和疏散通道。

拍前擦镜头，试拍检查对焦和曝光。固定机位可锁定合适焦点/曝光，避免反复拉焦与亮度跳变；不支持手动锁定的手机记录设置即可。白平衡按现场光源设置，不强制固定色温。

避免超广角导致球太小，避免数码放大代替有效细节。手机2x/3x按钮不一定代表独立光学镜头；以原片细节和镜头实际行为为准。拍摄期间避免变焦、切镜头和随球摇动。

关闭美颜、滤镜、电影虚化和会改变时间轴的慢动作模式。优先普通SDR录制；HDR、电子防抖或可变帧率若无法关闭，应如实记录并先验证解码。不要强制关闭不可控的硬件防抖。

室内先录10秒检查条纹频闪、拖影和噪点；快门/帧率按灯光实测调整，不统一强制1/500秒或ISO上限。暗光下60fps未必比30fps更清楚。

准备存储、电量和散热，勿扰模式防中断。出现过热提示先停止并安全降温，不忽略警告。机位移动时记下时间、分段重拍场景参考；已有片段仍可按可见范围使用。

## 04｜拍什么：覆盖真实变化与负样本

第一轮建议同一会话录一段连续投篮/上篮和一段自然对抗；优先自然发生，不要求为了凑配额强行完成动作。命中和未中均保留，不能只交精彩集锦。

投篮覆盖：近/中/远距离、不同方向、定点/运球后出手、上篮/抛投。逐步加入干扰、遮挡、篮下多人、球打板/弹筐、盖帽和补篮。无法从画面判断结果时保留unknown。

负样本要真实：传球经过篮筐附近、运球、假投、抢篮板、暂停、无球画面、球出画、无出手片段。没有事件也有价值；未看完整的片段不能标为“无事件”。

战术覆盖：挡拆及后续、空切/溜底线、传切、手递手、掩护、转换等。保留配合前后的上下文和失败/被破坏的配合；不强行归类，每段允许多标签或未知。

泛化采集按会话扩展：不同场地、日期、设备、机位、室内外、白天/夜间、服装和参与者。先保证每类有可核验样本，再根据错误统计补缺，不只堆同场同角度重复视频。

首轮可争取约30–50次有清楚结果的出手作为开发素材，但不要求在固定时长内凑够。用于最终评测还需独立场地/会话和更充分样本；少量成功案例不能证明大众场景泛化。

连续原片用于主验证。剪辑、回放、配乐、字幕或网络转码素材单独标识，可作参考，不能冒充连续实拍或重复计数。

## 05｜标定、多机位与记录信息

只做球/筐检测和出手事件核验，不强制提供米制标定。若要输出米制轨迹、距离、速度或基于场地的区域判定，才需要额外的场地几何和质量验证；标线清楚也不代表当前模型已具备该能力。

固定机位拍10秒空场或低遮挡参考视频，并保留原视频中的参考帧。额外照片可辅助理解，但照片可能使用不同镜头/裁切，不能直接替代视频标定。

进阶标定：至少4个不共线、分布覆盖目标区域的地面对应点，推荐更多检查点。优先现有标线交点；临时贴点须获场地许可并确保不打滑。篮筐不在地面上，不能直接当作地面点。

记录实测尺寸、点位示意和统一坐标原点/方向/单位；未知尺寸留空。不要照抄标准场地数值。旧版示例把11米与15米坐标混用，本版移除未经现场确认的坐标表。

机位、焦段、电子裁切或分辨率变化后另建camera_segment并重新参考。地面单应性只适用近似平面的地面点，不能直接恢复空中篮球的三维位置。误差须说明图像分辨率及独立检查点，不采用统一5像素门槛。

多机位可选：每个机位单独原片和ID，拍一次共同可见/可听的同步信号，记录起始偏移及长片漂移。不要把两个机位当成两次独立比赛。

notes记录：session_id、日期、场地匿名ID、训练目标/赛制、设备、镜头、分辨率/帧率、室内外/光照、机位、已知中断/移动、可见区域、参与人数及允许用途。无需提供电话、地址或真实姓名。

## 06｜人工答案：不猜测，保留不确定性

先选有代表性的连续小片段，完整标完其中所有目标事件，再扩大数量。标注用于检查模型，不可直接用模型输出充当真值。代表性抽查只能确认抽查范围。

投篮记录建议字段：source_id、session_id、camera_segment、event_id、release_time_s、outcome_time_s、team_id、player_id、action_type、points、result、visibility、review_status、notes。

action_type记录jump_shot/layup/floater等动作，points单独记录1/2/3或unknown，不能混成同一字段。result用made/missed/unknown；罚球另记场景。不同赛制按实际规则记录分值，不凭场地猜。

时间以解码原片起点为零，使用秒和小数，必要时附帧索引；出手时间是球离手，不是入网或记分牌变化。看不清离手或结果就记unknown并说明遮挡。现场粗记可用，最终需逐帧核验，容差在评测方案里预先定义。

战术记录开始/结束时间、类别、参与者、可见证据和未知原因；动作发生不等于战术成功。检测框另建任务标签：篮球、hoop_region等定义与仓库一致；不把篮板框冒充篮筐区域，不把未穷尽标注当负样本。

独立复核关键出手与争议段，分歧保留并再裁决，保留标注版本、复核人匿名ID、源文件哈希和修改历史。看不清的部分不因“通过审核”就变成精确真值。

按来源/拍摄会话分组后划分train/val/test，同场多机位及切片保持关联，避免近重复泄漏。最终盲测在调参前锁定；已看过并用于改模型的视频只能称开发评测。

## 07｜交付目录与可信数据入库

建议目录：session_001/originals/保存原始视频；reference/保存参考视频、照片与可选场地图；notes.md保存会话信息；labels/保存标注；SHA256SUMS.txt保存校验信息。

每个文件有稳定source_id。若重命名，保留原始文件名映射；不改编码、时长或帧率。MP4/MOV等能正常解码的原始容器都可试用。传输选“文件/原文件”，不用聊天视频压缩版；传后校验哈希。校验可由项目方代做。

必须先确认参与者知悉采集及允许用途，涉及未成年人需取得适当监护同意。内部分析、模型训练、公开演示分别确认；不把同意拍摄等同于同意公开人脸。采用匿名ID，控制原片访问；原片和个人名单不推到公开GitHub。

入库四步：原片登记与哈希 → 解码/可见性检查 → 任务标注及独立核验 → 冻结带来源与版本的数据集。未审核、未知用途、标签不完整、重复或冲突数据进入隔离/待办，保留原因。

“素材收录”“人工通过”“允许训练”“可作盲测”分别管理。无标签素材也可收录；只有批准用途、任务标注充分且分组无泄漏的数据才进入相应训练导出。

当前登记命令：python3 scripts/intake_video.py '/绝对路径/视频.mp4' --source-id phone-001 --group-id court-a-session-001。此命令只生成本地待审核登记，不自动进入审核界面、不自动标注或训练。

第一批建议交：30–60秒试拍原片 + notes + 同机位参考。确认后交连续原片；没有精力标注可以留空，由项目方安排，不用为凑“标准答案”猜结果。

## 08｜现场核对与异常处理（可单独打印）

开拍前：目标任务已明确；镜头干净；机位安全稳定；目标人物/球/筐按任务入画；存储电量足；快速运动试拍清楚；没有持续频闪/严重虚焦；参与者知悉用途。

试拍回放：检查最远和最近位置、一次出手全过程、动作最高点、遮挡和结果。身份任务才检查背号。画质不足先靠近/调整取景/改善光线，再考虑设备升级。

正式录制：连续拍摄，尽量不摇、不变焦、不切镜头；记录中断与机位变化；定时查看是否仍录制。过热则安全停机降温。不要为拍摄干扰比赛或让人员进入危险位置。

收工前：打开原文件确认可播放、时长完整；保留实际设置；参考/notes齐全；标明无法确定的事件和遮挡区；传输原片并保留本地备份。

可用但限定范围：背号看不清→不做按人身份验收；画面只覆盖局部→只评可见区；无标定→不声称米制准确；机位移动→切段或作为移动场景；结果遮挡→该事件结果未知，不猜进球。

需要重传/补拍：文件损坏、仅剩压缩预览、目标长期不在画面、严重模糊到无法人工核验。先保留原记录并写原因，不静默删除。拍摄许可未确认时暂停相应用途。

最终验收由项目方基于原片抽帧、任务标签及实际模型结果完成。当前没有“按本任务书拍摄就保证识别成功”的承诺。
