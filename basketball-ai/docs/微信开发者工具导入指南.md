## 一、安装微信开发者工具

下载地址（选**稳定版 Stable**）：

```
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
```

Windows 版直接安装，装完用微信扫码登录。

## 二、导入项目

打开工具 → 左侧选 **小程序** → 点 **「+」导入项目**，按下表填写：

| 字段 | 填什么 |
|---|---|
| **目录** | `C:\Users\CC\Desktop\自研app\basketball-ai\miniprogram` |
| **AppID** | 点「测试号」链接现申请一个，或选「不使用 AppID（游客模式）」 |
| **项目名称** | 任意，例如 `篮球数据` |
| **开发模式** | 小程序 |
| **后端服务** | 不使用云服务 |

点 **确定**，等待编译完成。

### ⚠️ 目录必须选到 `miniprogram` 这一层

**不是** `basketball-ai`。

原因：`project.config.json` 位于 `miniprogram/` 内，且没有配置 `miniprogramRoot`，
工具会把「导入的目录」直接当作小程序根目录。选错层级会导致找不到 `app.json`。

### 关于 AppID

`project.config.json` 里的 `appid` 已设为**空字符串**：

```json
"appid": ""
```

留空 → 导入时工具会弹出选择框，可现场选「测试号」或「游客模式」。

> 原先的占位值 `TO_BE_FILLED_P0_04` **不是合法 AppID 格式**（合法格式为 `wx` 开头的 18 位字符串），
> 工具会直接拒绝导入，所以改成了空字符串。
>
> 拿到 P0-04 申请的正式 AppID 后，把它填回 `project.config.json` 的 `appid` 字段。

## 三、导入后确认三件事

### 3.1 控制台无红色报错

底部 **调试器 → Console**。应该只有少量 warning，不该有 error。

如果出现 `module not found` 或找不到 `app.json`，说明**目录选错了层级**（见上一节）。

### 3.2 模拟器出现底部四个 tab

```
首页  |  球队  |  历史  |  我的
```

**只有文字、没有图标是正常的。** tabBar 的 `iconPath` 是可选字段，第一版没做图标资源。

需要图标时：往 `miniprogram/assets/` 放 81×81 px 的 png，再在 `app.json` 的
`tabBar.list` 每一项里加 `iconPath` 与 `selectedIconPath`。

### 3.3 首页能看到内容

应显示：球队名「雷霆 U16 青年队」、橙色的待补录提醒卡、最近活动列表。

数据来自 `mock/data.js`，**不需要后端**。

## 五、必看的两个对照验证

### 5.1 参数降级：5对5 vs 3对3

先选 **「报告总览（Mock）」**，再选 **「3对3 报告」**，对比着看：

| 位置 | 5对5（act_1009） | 3对3（act_0928） |
|---|---|---|
| 比分卡 | `78 : 65` | `21 : 18` |
| 比分卡说明 | 4 节 × 8 分钟 · 24 秒进攻时限 | 单节 10 分钟或先得 21 分 · 12 秒进攻时限 |
| 计分口径条 | 弧内 2 分 / 弧外 3 分 | 弧内 1 分 / 弧外 2 分 |
| 时间轴 | 4 节色带 | 单节 |
| 关键指标 | 「三分」8/22 | 「远投(2分)」 |
| 快攻指标 | 数字 | 「不适用」+「12秒下已关闭」 |
| 精彩片段入口 | 可点 | 变灰，点击提示不可用 |
| 球场图 | 全场双框，三分线含底角直线段 | 半场单框，纯弧线 |
| 告警条 | — | 多一条「快攻识别已关闭」 |

**这些不是写死的界面分支**，是 `mock/report.js` 根据 `params` 真实算出来的。
这也是开发计划第十三节要求「Mock 必须真实响应 params」的原因——
如果 Mock 永远返回同一份成人 5对5 报告，前端就测不到降级路径，
等真实 pipeline 接入时会集中爆雷。

### 5.2 补录闭环（产品生死线）

进 **「事件补录（Mock）」**：

1. 点任意一张**橙色**卡片 → 底部浮层弹出
2. 点一个球员头像 → **立刻保存并自动跳到下一个未补录事件**（不需要点保存按钮）
3. 连点几次，观察顶部进度条实时上涨
4. 点「撤销」可回退，支持连续撤销（栈上限 200）
5. 试「看不清」→ 列表里显示 `—`，**不会填入任何球员**
6. 试「不是我方」→ 显示「不是我方」，`player_id` 同样为 `null`

这条路径对应 PRD 7.1：单个事件 3-5 秒，27 个待补录约 3 分钟扫完。
没有「保存 · 下一个 →」这个按钮的话，一场要 15 分钟，**差 5 倍**。

> PRD 9.3 #3.10 的验收标准是「单个事件补录耗时中位数 ≤5 秒」，
> 需要找 ≥3 位教练各测 ≥20 个事件。**这个只能在真机上实测。**

## 七、常见问题

### 7.1 报基础库版本问题

`project.config.json` 里写的是 `"libVersion": "3.5.0"`。
如果工具没装这个版本，会提示下载或报错。

**解决**：详情 → 本地设置 → **调试基础库**，选一个已安装的最新版本即可。
代码没有使用任何 3.5 专属 API。

### 7.2 `tests/` 或 `preview/` 目录被打包

已通过 `packOptions.ignore` 排除：

```json
"packOptions": {
  "ignore": [
    { "type": "folder", "value": "tests" },
    { "type": "folder", "value": "preview" }
  ]
}
```

这两个目录不是小程序代码：`tests/` 用 Node 的 `node:test`（`require('node:test')`
在小程序环境不存在），`preview/` 是浏览器预览用的 bundle。
它们仍留在目录里供 `node scripts/verify.js` 使用，但不会进包。

### 7.3 提示 `permission` 字段无效

已处理。`app.json` 的 `permission` 字段**只支持** `scope.userLocation` 与
`scope.userLocationBackground`，写 `scope.camera` 会报无效字段。

摄像头授权改为运行时申请，见 `pages/record/index.js` 的 `_ensureCameraAuth()`：
先 `wx.getSetting` 查状态 → 未决定则 `wx.authorize` → 曾拒绝则引导 `wx.openSetting`。

### 7.4 控制台提示找不到后端接口

正常。`utils/api.js` 顶部 `USE_MOCK = true`，所有数据走 `mock/`，不发网络请求。

### 7.5 tabBar 图标缺失警告

正常，见 3.2 节。`iconPath` 是可选字段，纯文字 tabBar 合法。

## 八、切换到真实后端

只需改一处：

```js
// miniprogram/utils/api.js 顶部
const USE_MOCK = false;   // 原为 true
```

改完所有方法自动走 `wx.request` 分支，**页面代码一行都不用改**
（开发计划第十三节「Mock 与真实实现可开关切换」的落地）。

同时需要做两件事：

1. 在 `app.js` 的 `onLaunch` 里配置后端地址：

   ```js
   const api = require('./utils/api');
   api.setConfig({
     apiBase: 'https://api.your-domain.com',
     cdnBase: 'https://cdn.your-domain.com',
   });
   ```

2. 在小程序后台配置 **request 合法域名** 与 **downloadFile 合法域名**。

> `setting.urlCheck` 当前是 `false`，开发期不校验域名白名单。
> **正式发布前必须改为 `true` 并配好域名**，否则线上会被拦。

### B 轨需要提供的端点

`utils/api.js` 已按这些签名调用，路径可协商但**响应结构必须符合契约**
（`docs/contract/report-schema.json`）：

```
GET  /teams/current
GET  /roster
GET  /activities?template=&format=&status=&opponentId=
GET  /activities/:id
POST /activities                          ← 服务端必须再校验年龄段与赛制必填
GET  /activities/:id/upload-credential    ← STS 临时凭证
GET  /activities/:id/process-status
GET  /activities/:id/report               ← 契约 report-schema.json
PUT  /activities/:id/events/:eid/attribution
GET  /tactics          POST /tactics
GET  /opponents        GET  /opponents/:id
```

## 十、不想装开发者工具？先看浏览器预览

`miniprogram/preview/index.html` 是一个**由真实代码驱动**的浏览器预览：

- 球场 SVG 由 `utils/svgBuilder.js` + `utils/courtGeometry.js` 实时算出
- 报告数据由 `mock/report.js` 按当前 `params` 真实生成
- 补录交互跑的是 `utils/attribution.js` 状态机
- 样式编译自 `styles/*.wxss`（rpx → px 换算）

双击 `index.html` 即可打开，左侧可切 5 个参数组合，9 个屏可交互。

**注意边界**：预览页的布局标记是手写镜像，不是编译自 wxml。
它能验证「几何算对了、数据算对了、状态机跑通了、样式令牌是对的」，
不能验证「wxml 模板语法、`wx.*` API 行为、真机排版」。
真实页面仍需开发者工具。

预览资源需要重新生成时：

```bash
node scripts/build-preview.js
```

（`verify.js` 已包含这一步，改过 `utils/` 或 `mock/` 后必须重跑，否则预览跑的是旧代码。）
