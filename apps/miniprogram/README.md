# 微信小程序：本地录像复核原型

用微信开发者工具导入本目录，测试 AppID 可使用游客模式。开发设置关闭合法域名校验。

仓库根目录启动后端：

```sh
PYTHONPATH=packages/params:services/api python3 -m uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8000
```

模拟器使用 app.js 默认地址；真机调试将 apiBase 改为电脑的局域网 IP。上线需要正式 AppID、HTTPS 域名、登录鉴权、媒体存储与部署，目前不能直接公开部署。

目前仅提供两场 NBA 各自原视频第 600–620 秒的本地测试片段。主客队由用户确认，统计来自人工记录，可撤销、可点击跳转。数据保存在 API SQLite 数据库，不属于自动生成的正式比赛报告。

尚未实现：相册上传、后台分析任务、自动投篮检测、球员身份、完整比赛与场地标定。NBA 转播不得用作对外发布的内置素材。

## 第一次操作

1. 双击仓库根目录「启动篮球助手.command」，保持终端窗口打开。也可在终端运行 `./scripts/start-local.sh`。
2. 安装并打开微信开发者工具，导入本目录。使用测试号或游客模式；如工具要求账号，请用你自己的微信登录。
3. 在开发设置中关闭合法域名校验，编译工程。
4. 首页点击比赛，播放视频，在出手位置点击「记录投篮」。设置球队、2/3 分与命中后保存。
5. 检查下方统计；点击记录跳回出手时刻；点击撤销检查统计归零。关闭页面重新打开，记录应保留。

默认启动脚本仅监听本机，供模拟器使用。手机访问需另行开放局域网监听和修改 apiBase。

已验证：两段视频可读取、HTTP Range 分段播放（206）、记录跨应用重建持久化、撤销后重算、22 项 API 测试。尚未验证：微信开发者工具编译与实际视频组件播放；当前机器未发现微信开发者工具。当前环境没有 Node，未运行 JavaScript 语法检查。
