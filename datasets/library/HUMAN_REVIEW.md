# 逐条人工审核

运行 `./scripts/start-review.sh`，浏览器打开 http://127.0.0.1:8010/ 。仅监听本机，首次播放战术上下文会按登记来源生成短片。

1. 填写审核者姓名或昵称。
2. 看绿色目标框，或完整播放事件片段，核对显示的标签。
3. 正确则勾选已查看证据，点击通过；有错误或不清楚则填写原因，选择需修改或驳回。
4. 每次提交直接保存 SQLite，刷新页面保留进度。取消“仅看未提交”可重新审核，最近一次决定生效，旧决定不删除。

审核队列含 43 条现有标注。模型候选不混入此队列。战术通过时必须额外选动作、填原视频起止时间和描述参与者及动作证据；上下文不足不勉强批准。

human_decisions 保存全部人类操作；human_clean_annotations 只保留最新通过且原标注、媒体哈希、审核范围均未变化的记录。原标签或媒体版本变化会让通过状态失效，须重新审核。`/api/export` 查看人工确认库。

“通过”只确认本条用途，不自动批准用于训练或认定精确金标准。框不准、时间不准时先选择需修改，避免把修改意见直接当成已经修正的标签。

数据库仍为 data/library/library.db。自动化测试只在临时副本提交测试票，不会替用户审核真实素材。写操作需要同源审核页面的会话令牌，服务不对局域网开放。
