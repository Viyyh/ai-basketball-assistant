# PL-NBA 全量结构审核与代表样本

已参考作者 README 核对任务与获取方式：作者提供标注 ZIP，预剪辑视频另有网盘入口。作者描述的是动作与结果，不能直接把 Dribble/PassBall 解释为团队战术。字幕描述可能由模型生成，不作为独立证据。

`python3 scripts/audit_external_annotations.py` 逐条检查 6408 回合、31964 事件，保留原始 JSON 不改写，另存 external_quality。

- 6262 回合：在已实现规则下未发现错误/警告，只通过结构检查，未验证画面。
- 19 回合：存在明确结构问题，隔离。
- 127 回合：存在需复核的一致性问题。
- 18 个非正时间区间、4 个未知类别、1 个传球结果为 score 等异常按条记录。119 个回合的标注序列相同，不代表视频必然重复，保留待查。
- Putback 统一为 PutBack 共22条，原字段仍保留。
- 时间字符串常见 04:20，但秒/帧或小数含义未确认，不转换成真实秒，不用此字段自动裁视频。

现有两个 NBA 原片恰好覆盖外部的两个比赛分组。按回合编号正确数值排序（不能按字符串/日期排序），用连续球员+分值+结果序列，在各自比赛标注内各找到一组唯一候选，关联到已有9个局部出手片段。它是候选关联，不证明整段回合正确或所有动作都在局部片段里，审核只针对目标出手。

代表队列共29条：9条候选视频对照，16类动作覆盖，以及4类异常例子。后20条没有已匹配视频，只能审核文本结构；接口阻止无视频记录获得视觉通过状态。样本是有目的抽样，不是用于估计总体准确率的随机样本，不能把通过比例当作全库准确率。

运行 `python3 scripts/review_external.py` 后访问 http://127.0.0.1:8012/ 。默认只显示9条视频。请确认是否同一次出手，再核对外部动作、球员与结果；如“抛投”被笼统归为 Layup/2ptShot，可以写具体意见。目标事件通过不批准其他回合事件，也不会训练就绪。

external_sample_reviews 单独保存你的审核，不修改原有43条 human_decisions。回合标注、审核理由、样本版本和原始字段均保留。没有更换本项目模型，也未将这些非商业研究数据纳入产品训练。

脚本测试：4项通过，包括别名规范化、时间不擅自转换、零区间、字幕自相矛盾、重复事件ID、无视频禁止视觉通过、令牌、版本冲突和原有审核保留。完整机读统计见 data/public-sources/pl-nba-audit/summary.json。
